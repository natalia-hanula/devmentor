# Spacing and layout

One scale — **4, 8, 12, 16, 24, 32, 48 px** (Tailwind steps 1, 2, 3, 4, 6, 8, 12) — and one token per relation. Pick the token by the relation between two things, not by eye (tokeny.md).

"Dense on lists, calm in conversation" (K1, K2): list rows are tight with 1 px dividers; session messages are separated by space, not lines.

| Rule | Source |
| --- | --- |
| Only the scale steps above. No arbitrary values (`p-[13px]`); `npm run lint:tokens` fails on them. | Prompt, rule 3 |
| Use the relation tokens first; a plain scale step (`gap-3` = 12 px) only inside a component when no relation fits. | tokeny.md |
| List rows: no card, no shadow, no row background; hover uses `accent`. | R01.1, R01.3, Z4 |

## Layout

| Width | What changes | Source |
| --- | --- | --- |
| 320 px | One column. Tables scroll horizontally inside their container, never the page. Page gutter 16 px (`px-4`). | Prompt stage 1, WCAG 1.4.10 (reflow), P3 (accepted 2026-10-19) |
| 768 px | Two columns where content allows (form + help). | Prompt stage 1 |
| 1440 px | Panel content stops at `max-w-panel`; the page does not stretch further. | Prompt stage 1 |
