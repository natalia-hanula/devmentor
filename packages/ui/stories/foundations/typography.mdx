# Typography

One readable typeface for the whole interface — **IBM Plex Sans** — and **IBM Plex Mono** only for code, file names, versions and prices (W02, R01.2, Z6). Fonts ship with the package (`@fontsource`, includes Polish `latin-ext`); nothing loads from a CDN.

Hierarchy comes from size **and** weight together, so a row title never carries the same weight as its metadata (R01.5, Z4).

## Roles

Use the role class, not a raw size (`text-sm`, `text-2xl`). Values are measured from the live CSS.

## Rules

| Rule | Source |
| --- | --- |
| Running text is at most about 65 characters per line: wrap paragraphs in `max-w-measure`. | Prompt stage 1 (≈ 65 ch) |
| One page title per screen; section titles below it, no skipped heading levels. | WCAG 1.3.1 |
| Weights in use: 400, 500, 600. No 300 or 700+. | W02 (only these weights are bundled) |
| Never use monospace for interface text or headings. | W02 |
| Prices always in `font-code` with `tabular-nums`, currency after the number (`150 PLN`). | Z6 |
| Text must survive 200 % zoom without clipping: no fixed heights on text containers. | WCAG 1.4.4 |
